Quick start

First route in minutes.

Install the CLI, scaffold an integration, and run it locally.

rust-camel — bash
~ ❯ cargo install camel-cli
~ ❯ camel new my-integration
~ ❯ cd my-integration
~/my-integration ❯ camel run
