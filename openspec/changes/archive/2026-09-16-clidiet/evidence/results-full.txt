## Load-controlled paired study (conductor, post-task; supersedes single-session timing verdicts)

Context: single-session timing bands FAILed in the favorable direction on
a box with loadavg 7-10 (parallel mission builds); a same-binary probe
showed 70->33.5 ms drift (RSS also drifted: marker 49,832->33,276 kb,
help 19,600->14,340 kb on an UNCHANGED binary), proving single-session
+/-5% timing and +/-2048 kb RSS comparisons are below the session noise
floor. Protocol fix: paired, same-load-window comparisons with a
base-vs-base control.

### Paired marker, interleaved 3x n=10 chunks (tags pairB*/pairF*; raw in results/)
- timing: base median 21.5 ms, post median 22.0 ms -> +2.3% (band +/-5%) PASS
- RSS: base median 30,644 kb [30,452-30,868], post median 33,156 kb
  [32,900-33,412] -> +2,512 kb, OUTSIDE the +/-2,048 kb band, ranges
  disjoint. Verdict: INCONCLUSIVE (regime noise between chunks; not
  attributable to the dedup: identical default closure per the golden
  test, mimalloc never linked in default builds, size identical — the
  offset pattern matches allocator arena/layout placement differences
  under different load regimes; single-session marker RSS drifted 33%
  on an unchanged binary in the same window).
