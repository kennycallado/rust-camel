boots an http route"): no dangling forward such as otel without the http
bridge, and the LSP-free binary still parses and boots routes.

cites the deltas as measured, single-session, same protocol for both

−40.3% help RSS, −47.0% size, −37.2% closure — all consistent with dropping
the controllable optional surfaces (kafka/grpc/wasm/llm/mcp/mqtt/surrealdb/
exec/lsp/lang-*), which the full build links but the slim build excludes.
